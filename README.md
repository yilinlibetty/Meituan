# 周末出逃

上海大学生的周末探索指南。

### [点这里打开在线体验 →](https://yilinlibetty.github.io/Meituan/)

电脑上打开是左侧产品说明加右侧手机原型，手机上打开就是全屏 App。

## 做了什么

跟 AI 说一句想怎么过周末，它按天气、预算和同行人数排一条上海周末路线，再帮你找到一起去的同学。去完打卡点亮上海地图，走过的路线一键发成攻略，留给下一个人照着走。

## 痛点和对应功能

| 痛点 | 对应功能 |
| --- | --- |
| 展览、市集、演出信息散在各个平台 | 推荐页集中展示，卡片写清地铁站、通勤时间和人均 |
| 条件多，筛选器难用 | 一句话描述需求，AI 听懂人数、预算、日期和想不想累，还能接着改 |
| 天气一变计划泡汤 | 周六周日分开排，下雨时户外活动自动让位给室内 |
| 想去但没人陪 | 按活动发起组队，学生认证后才能加入，AA 人均提前写清 |
| 去过就忘，攻略懒得写 | 打卡点亮地图，AI 路线或打卡记录一键发成攻略 |

## AI 规划的思路

1. 大模型把对话抽成结构化条件，包括日期、人数、人均预算、出发校区、兴趣、强度和是否只去室内
2. 规则引擎按天气、预算、人数、通勤时长打分，每条推荐都写明理由
3. 按上午、下午、晚上挑分最高、预算够用、品类不重复的活动，生成路线

原型里第 1 步用关键词规则模拟，正式版接入大模型。排序交给规则引擎，结果可解释，运营也方便调权重。

## 推荐体验路径

1. 点底部中间的 AI，输入「周日和室友三个人，人均一百，想拍照但别太累」
2. 接着说「不想去户外」或「预算再低一点」，看路线怎么变
3. 回首页切换周六周日，或在天气里点「高温」，推荐顺序会跟着变
4. 在活动详情里打卡，到「足迹」看点亮的上海地图
